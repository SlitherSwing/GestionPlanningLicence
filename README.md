## Projet de Gestion des plannings des élèves de Bachelor ##


# Présentation du projet # 

Ce projet consiste à créer une application web de gestion des plannings des élèves de Bachelor. Ce projet est encadré, et regroupe un ensemble de fonctionnalités et technologies acquises tout au long de l'année. 

# Technologies utilisées # 

L'objectif principal est de mettre en pratique les différentes connaissances acquises depuis le début de l'année, qu'elles soient encadrées ou par les veilles technologiques personnelles. 
Ici, le projet est réalisé en : 
- HTML
- CSS
- PHP
- MySQL

On utlise les également les outils suivants : 
- Figma (https://www.figma.com/design/AJZ4aDQO3E0v3PW0HmlhmR/Enseignement-sup%C3%A9rieur---light?node-id=0-1&p=f&t=uacK3uZWILZf2u79-0)
- Git 
- GitHub (https://github.com/SlitherSwing/GestionPlanningLicence)


# Organisation #

Le projet est découpé en sprint d'une semaine, visible dans l'onglet "**milestone**" sur GitHub. Un découpage des tâches a été réalisé au préalable et intégré dans GitHub sous forme d'**issues**. Chaque issues décrit une tâche précise à réalisé, et est assignée à une collaborateurs et un sprint précis. 
Nous sommes en groupe de 4 + 1 élève en observateur 

# Démarrer le projet # 

Pour démarrer le projet, il faut déjà créer une base de donnée dans laquelle, un jeu d'essai sera nécessaire afin de s'assurer que le projet fonctionne au cours de son développement. 
Ensuite il faudra commencer par la coque, la structure HTML et CSS, qui permettra d'insérer le plus gros du projet. 
Il faudra ensuite s'attaquer à la partie PHP, qui permettra de faire la liaison entre les éléments en HTML et la base de donnée. 
Vous trouverez un exemple de fichier de connexion à la base de donnée dans le fichier `Public/Credentials.example.php`

# Conventions # 

Les conventions utilisées dans le projet sont les suivantes : 
- Les noms utilisés pour les classes etc. sont tous en **anglais**
- Une majuscule doit être mise sur le début de chaque mot. 
- Chaque mot est séparé par un tirêt 
- Chaque tâche qui requiert une structure HTML différente est mise en place sur une branche qui lui attribuée.
